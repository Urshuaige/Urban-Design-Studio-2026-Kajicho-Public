# Domain candidates

`Kajicho_Domain_Candidates.gpkg` contains four EPSG:6677 layers: completed 6H geometry, more distant tall buildings, continuous 750 m + 10H geometry, and air-domain boundaries. `Domain_Audit.json`, `Wider_Building_Screen.json` and `Small_Object_Review.json` record geometry checks. `Sensitivity_Plan.json` and `Next_Run_Inputs` retain candidate inputs and comparison criteria.

See [CFD domain](../../../docs/CFD_DOMAIN.md) for extent definitions and sources. The completed-6H reference and light trials ended without passing every numerical check; the other domain comparisons have not been run. [CFD status](../../../docs/CFD_STATUS.md) records the scientific state. Personal process and upload receipts are not inputs to this folder.
