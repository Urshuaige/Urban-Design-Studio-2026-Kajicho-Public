## Findings · 结果

以神田站东自转车停车点 P1 为起点，在步速 1.2 m/s、信号等待 0 s 的模型中：东口约117 m / 1.6 min；北口201 m / 2.8 min；南口257 m / 3.6 min。这是沿地表路网的到站口时间，未加入停放操作、进站、楼梯、电梯或站内换乘时间。1 / 3 / 5 min 的行走预算分别为72 / 216 / 360 m。

P1到东口在1.0–1.4 m/s时为1.95–1.39 min，南口为4.29–3.06 min。各速度和各停车点完整结果在 CSV 与 `reachable_segments` 中，图面默认1.2 m/s。这些速度情景不是统计置信区间。

## Network · 路网与算法

1. 读取已准备的 `../Isochrone_Handoff_2026-11-02/Data/Kajicho_Isochrone_Inputs.gpkg` 原始 highway ways 与节点。17,518条上下文ways，以11月1日本地资料替换999个同ID ways，加入82个新ways。源节点坐标更新逐项记录在 `QA/Network_QA.json`。
2. 按原OSM节点ID连接，不把同坐标顶点或二维交叉自动连通。保留桥梁、隧道、layer、level与原标签。铁路、高速不是步行网络；排除明确禁行、私人、地下、室内、站台与标记出的站内段。步行单向及方向禁行单独处理，机动车单行不自动限制行人。已审读14个局部转向限制关系，均无显式restriction:foot；普通机动车转向限制未套用到行人。原数据未标明的门禁和站内属性仍有遗漏可能。
3. 53,704条实体边、107,400条方向弧、42,147个节点、123个弱连通分量，最大分量40,977节点。保留真实死胡同。仅移除58条同端点、同层级和同权限重复边。
4. 每个起点独立用有向Dijkstra计算。离网点仅使用自己的临时源节点，计入短连接长度，不建立起点之间的捷径。阈值处按剩余距离精确截取边，不只是筛选已到达节点。
5. 同一实体边的两个方向区间合并；统计长度另按相同层级几何合并，避免反向弧重复计长。四点合并图是独立可达路段的并集，没有重新接通各起点。
6. 输出以可达线为准，未生成凸包或跨河填满的多边形。三种速度1.0/1.2/1.4 m/s，1/3/5 min，等待0 s；没有伪造信号周期。

完整上下文查询框WGS84为[139.7505,35.6725,139.7955,35.711]，约3.7×4.3 km；完整OSM ways可延伸出框，不能把外伸长度理解为完整数据覆盖。最大速度下全部5 min结果仍在查询框内。显示范围与既有wider专题一致：[-5902.94,-34762.45,-5011.94,-33547.45]，图框198×270 mm，1:4500。图框裁切只是展示，不是计算边界。

未制作骑行5/10/15 min：现有字段尚不足以核验局部骑行转向、逆行豁免及人行道骑行规则，不能把这张步行网简单加速冒充骑行分析。
