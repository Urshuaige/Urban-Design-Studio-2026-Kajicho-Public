# Obsolete CFD cleanup

20 October 2026. The user authorized removal of obsolete server CFD data. Process and container checks found no active solver or process using the three old trial roots. No process was stopped.

Deleted 702 generated directories: parallel processor partitions, positive-time field directories, generated meshes, post-processing folders and dynamic-code outputs. The recorded allocated-storage reduction was **32,759,418,880 bytes, about 32.76 GB (30.51 GiB)**. Allocation is reported rather than summing logical hard-linked file sizes.

Preserved original inputs and CityGML, initial conditions, system settings, code, logs, numerical checks, reports and exported teaching snapshots. Current Figure 5 GIS, map delivery, source LOD2 assets and Site data were outside the deletion set.

The old native checkpoints and meshes are no longer available to resume. The retained iteration-100 teaching fields still show unconverged historical trials; they are not a validated current-scope baseline. New work requires current physical inputs and a question-specific verification plan.

The internal plan, exact target list, process checks and before/after receipt are retained in the designated team research records under `07_Team/Review/CFD_Cleanup_2026-10-20/`. They were not copied to a local download folder. No replacement simulation was started.
