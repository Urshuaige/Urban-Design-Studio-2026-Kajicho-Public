# Shared working rules

- Continue from README.md, docs/CURRENT_DELIVERY.md and docs/PROJECT_PLAN.md; resolve current main and active PR before new work.
- Keep official sources unchanged. Record URL, source year, download date, CRS, spatial unit, license and processing for derived data.
- Current membership, team decisions, run state and delivery history belong in project state and reports, not this file.
- Preserve Figure 5 source traces. Analysis buildings must have full original footprints covered by the chosen outline. Keep surrounding geometry separately when physical models need it.
- Keep QGIS sources relative and coordinate one editor per project or GeoPackage. Map exports are PNG; JPEG previews are allowed; do not export SVG maps.
- Keep generated outputs on their designated remote/project paths. Do not copy deliverables to Downloads unless requested. Preserve existing sharing settings.
- Use the connected Drive tools for Drive work. Honor requested write-acknowledgement-only uploads without content readback.
- Read only task-relevant evidence. Use local Git and authenticated gh for this repository. Private Sites use the recorded source and Sites connector.
- Keep facts, source evidence, inferences, proposals and numerical acceptance distinct. Use short English labels with Chinese explanations where helpful.
- Run checks for changed behavior. Scientific execution requires its authorized question, inputs and comparison; a work plan does not start simulations.
- Change shared agent rules, governance policies, task templates or rule checkers only in a dedicated PR against main. Before starting new work on a stacked branch, merge main; keep main's AGENTS.md on conflict.
- For substantive research planning, use research-workflow and the matching current-stage skill. Use academic-research-suite for source/literature or formal paper tasks, loading one relevant workflow. Apply academic-humanizer and anti-defensive-writing to user-facing text; use simple-english and tech-doc-style-chinese for the actual writing task.
- Follow [Compute policy](docs/COMPUTE_POLICY.md). Historical ended cases keep dated provenance; current run and cleanup state is recorded separately.
